# Recommended Resources — Azure

## Video

- **Adam Marczak — Azure for Everyone** (YouTube). Visual, slow-paced, beginner-friendly. Best if you want a video to go with a topic we've covered in class.
- **Microsoft Learn** — free, official, and includes a sandbox where you can try Azure without your own account or card: https://learn.microsoft.com/training/azure/

## Practice

- Microsoft Learn's AZ-104 learning path — the same topics as this course, in Microsoft's own words.

## If you don't have an Azure account yet

See Lab 00 in the [labs folder](.) first. If the student route still doesn't work for you, use the Microsoft Learn sandbox above — no account or card needed.
