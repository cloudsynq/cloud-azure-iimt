# Recommended Resources — Azure AZ-104

## Free Official Training
- **Microsoft Learn** — Free, official, browser-based labs (no account or card needed). Follow the AZ-104 learning path to go through every topic in this course.  
  👉 https://learn.microsoft.com/training/paths/az-104-administrator-prerequisites
- **Azure Free Account** — ₹13,500 free credits for 30 days + 12 months of free services.  
  👉 https://azure.microsoft.com/free

## YouTube Channels
- **Adam Marczak — Azure for Everyone** — Visual, slow-paced, beginner-friendly. Best for understanding how Azure services connect. Recommended to watch alongside each module.  
  Search: `Adam Marczak Azure` on YouTube
- **John Savill's Technical Training** — In-depth AZ-104 study cram videos. Very comprehensive. Good for exam prep.  
  Search: `John Savill AZ-104` on YouTube
- **Abhishek Veeramalla** — Practical DevOps + Azure content in Hindi/English.  
  Search: `Abhishek Veeramalla Azure` on YouTube

## Practice & Mock Exams
- **Microsoft Learn Practice Assessments** — Free official practice questions for AZ-104.  
  👉 https://learn.microsoft.com/certifications/exams/az-104/practice/assessment
- **Tutorials Dojo** — High-quality practice tests. Highly recommended for final exam prep.  
  👉 https://tutorialsdojo.com/microsoft-azure

## Documentation
- **Azure Docs** — Official reference. Use it to look up any service covered in class.  
  👉 https://docs.microsoft.com/azure
- **Azure Architecture Center** — Reference architectures and best practices.  
  👉 https://docs.microsoft.com/azure/architecture

## If you don't have an Azure account yet
See [Lab 00](00-introduction/lab-create-account.pptx) — it walks through the student account signup (free, no card needed with a college email). If that doesn't work, use the **Microsoft Learn sandbox** above which runs labs directly in the browser with no account or card.
